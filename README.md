# Struct-Caliper

Struct-Caliper brings accurate, calibrated, query-specific significance to protein **structure** search.
Foldseek and Reseek E-values are miscalibrated; Struct-Caliper searches a small set of
decoy queries (50), fits a per-query null from their best scores, and converts every real hit
score into a **Studentized-Gumbel (SG) p-value**. It runs on top of the
search tools, so the underlying search and its sensitivity are unchanged. 

- **Foldseek**: decoys are generated by a new `structureshuffle` module that shuffles the
  3Di and amino-acid strings with **independent first-order Markov chains** (decoy ids end
  in `_markovtog<N>`). 
- **Reseek**: decoys are generated inside `reseek -search` with the new `-num_shuffles N` option.

## Setup

### 1. Get the code and the data

To run Struct-Caliper directly on Foldseek or Reseek, clone this repository and the python scripts are available under src. The experiment inputs (`data/<experiment>/`) and the paper's results (`results/<experiment>/`) come from Zenodo (see [Data](#data)). 
```bash
git clone https://github.com/batmen-lab/Struct-Caliper.git
cd Struct-Caliper
```

After unpacking, the project looks like this:

```text
Struct-Caliper/
├── src/                          # the Struct-Caliper scripts for each tool             
│   ├── foldseek.py
│   └── reseek.py
├── libs/                         # modified Foldseek and Reseek sources   
├── scripts/build.sh              # quick installation script to compile Foldseek and Reseek into bin/   
├── tutorial/                     # notebooks reproducing the paper results       
├── data/
│   ├── lookup/m50.txt            # SG lookup table for 50 decoys          
│   ├── simulation/               # 5 query structures, SCOP40 targets     (Zenodo)
│   ├── scop40_run/               # SCOPe 2.08 structures, ASTRAL40 labels, Foldseek + Reseek target DBs (Zenodo)
│   └── dali_prefiltering/        # 73 query chains, AlphaFoldDB subset DB, thresholds (Zenodo)
├── results/
│   ├── simulation/               # decoy best hits and SG p-values        (Zenodo)
│   ├── scop40_run/               # all-vs-all hits with SG p-values: foldseek/, reseek/ (Zenodo)
│   └── dali_prefiltering/        # per-query hits with DALI labels        (Zenodo)
└── bin/                          # foldseek, reseek                       (built in step 3)
```

### 2. Python environment

```bash
conda create -n structcaliper python=3.11 -y
conda activate structcaliper
python -m pip install -r requirements.txt jupyterlab
```

### 3. Build Foldseek, Reseek or Both

Build the modified sources bundled with this repository; stock binaries do not have
Struct-Caliper's shuffle options. Run these commands from the repository root.

| Platform | Command |
|---|---|
| Linux x86-64 | `bash scripts/build.sh --system linux` |
| macOS Intel/Apple Silicon | `bash scripts/build.sh --system macos` |
| Windows x86-64 via WSL2 | `bash scripts/build.sh --system windows` |


```bash
bash scripts/build.sh --system linux --dry-run   # show commands without building
JOBS=8 bash scripts/build.sh --system linux      # limit parallel compilation
bash scripts/build.sh --system linux --tool foldseek    # if you wish to only build Foldseek
bash scripts/build.sh --system linux --tool reseek      # if you wish to only build Reseek
bash scripts/build.sh --system linux --tool both        # default
```

Both binaries end up in `bin/` (`bin/foldseek`, `bin/reseek`). To call them from any terminal,
add `bin/` to your `PATH` permanently. Run this once, from the repository root:

```bash
echo "export PATH=\"$PWD/bin:\$PATH\"" >> ~/.bashrc    # macOS (zsh): use ~/.zshrc instead
source ~/.bashrc                                         # or open a new terminal
which foldseek reseek                                    # both should point into Struct-Caliper/bin/
```

`$PWD` is written into `~/.bashrc` as the repository's absolute path, so this keeps working
from any directory. For the current terminal only, use `export PATH="$PWD/bin:$PATH"`.

## Run Foldseek with Struct-Caliper

`foldseek.py` runs four steps:

1. `createdb` on the query, unless it is already a Foldseek DB, then select one model/chain entry per structure.
2. `structureshuffle` to make `--num_shuffle` decoys for every query.
3. `easy-search` for the decoys and for the real queries.
4. Adds an `sgpval` column to every real hit.

`-query` can be a single structure, a directory of structures, or a Foldseek database
with many queries. With `--seed`, each query gets exactly the decoys, and so the SG
p-values, it would get if searched on its own.

```bash
python src/foldseek.py \
    --foldseek_url foldseek \
    --lookup_url data/lookup/m50.txt \
    --num_shuffle 50 \
    --seed 1 \
    easy-search \
    -query data/simulation/queries/d1stza1.ent \
    -db data/simulation/scop40_foldseek/scop_40 \
    -out results/d1stza1.tsv \
    --threads 32 -s 10.5 --max-seqs 1000 -e 1e9 \
    --alignment-type 2 \
    --shuf-comp-bias-corr 0 --shuf-gap-open 2
```

| Argument | Meaning |
|---|---|
| `--foldseek_url` | Foldseek binary built from `libs/foldseek` (stock Foldseek has no `structureshuffle`). |
| `--lookup_url` | SG lookup table; **must match `--num_shuffle`** (`data/lookup/m50.txt` is for 50 decoys). |
| `--num_shuffle` | Number of decoys per query. |
| `--seed` | Decoy RNG seed; same seed ⇒ identical decoys. Omit for a random draw. |
| `--overwrite 1` | Recompute retained intermediates when using `--keep-search-results`. |
| `--keep-search-results` | Retain original hits, shuffled hits, generated query databases and search caches. Default: retain only the `_sgpval.tsv` result. |
| `-query` | Query `.pdb`/`.ent`/`.cif`, a directory of structures, or a Foldseek DB (one or many queries). |
| `-db` | Target Foldseek DB or a directory of structures. |
| `-out` | Output name: `result.tsv` produces `result_sgpval.tsv` (`<stem>` below is `-out` without `.tsv`). Raw `result.tsv` is retained only with `--keep-search-results`. |
| `--threads -s --max-seqs -e --alignment-type -c --cov-mode --exhaustive-search --comp-bias-corr` | Passed to both searches. Any other unknown flag is passed to the real search only. |
| `--shuf-alignment-type`, `--shuf-comp-bias-corr`, `--shuf-gap-open` | Override the setting for the **decoy search only**. |
| `--fasta_url` | Optional FASTA with SCOP labels in the headers (e.g. `data/scop40_run/astral.fa`); adds the labelled copy `analyze_label/<stem>_sgpval.tsv`. |

`Note`: Foldseek takes each of the NMR ensemble as individual entry in a query's database. This creates **39,454** entries in a 15,177-structure SCOP40 database. To handle this, the wrapper automatically keeps the **lowest-key model-and-chain entry per input structure**. A single structure contributes one query entry; a directory contributes one entry per structure. For example, an NMR structure with entries `example_MODEL_1_A`, `example_MODEL_1_B` and `example_MODEL_2_A` contributes only its lowest-key entry (usually `example_MODEL_1_A`). This also selects one chain from multi-chain structures.


**Outputs** (next to `-out`):

**By default, only `<stem>_sgpval.tsv` is kept**. Raw original/shuffled hits, generated query databases and
search caches are temporary and removed when the run exits. Existing files and
input databases are left untouched; default runs perform fresh searches.

| File | Content |
|---|---|
| `<out>` | With `--keep-search-results`: raw Foldseek hits (`query target bits evalue`). |
| `<stem>_sgpval.tsv` | Same hits plus `sgpval`. A query with no decoy scores gets `NA`, with a warning. |
| `analyze_label/<stem>_sgpval.tsv` | With `--fasta_url`: adds `category` (−1 non-homolog, 0 same fold, 1 same superfamily, 2 same family). |
| `<out stem>/` | With `--keep-search-results`: original/selected query DBs, shuffled DB, `shuf_result.tsv` and search cache. |

## Run Reseek with Struct-Caliper

Unlike Foldseek, in which its `createdb` command automatically converts structure files like .ent and .pdb to its native databases, Reseek requires manual conversion of query files. Queries and targets must be Reseek `.bca` files. A `.bca` can hold one query or a directory of queries:

```bash
reseek -convert query.pdb -bca query.bca          # one structure
reseek -convert structures/ -bca queries.bca      # a directory of structures
```

Then run `reseek.py`:

```bash
python src/reseek.py \
    --reseek_url reseek \
    --lookup_url data/lookup/m50.txt \
    --num_shuffle 50 \
    search \
    --search data/simulation/queries/d1za_30.bca \
    --db data/simulation/scop_target.bca \
    --output results/d1za_30.tsv \
    --evalue 100 --verysensitive
```

| Argument | Meaning |
|---|---|
| `--reseek_url` | Reseek binary built from `libs/reseek` (stock Reseek has no `-num_shuffles`). |
| `--lookup_url` / `--num_shuffle` | As for Foldseek; they must match. |
| `--search`, `--db`, `--output` | Query `.bca` (one or many chains), target `.bca`, output TSV. |
| `--evalue --verysensitive --sensitive --threads --minlongdim --maxlongdim` | Passed to `reseek -search`. |
| `--keep-search-results` | Retain raw original and shuffled search results. Default: retain only the `_sgpval.tsv` result. |
| `--overwrite 1` | Recompute retained search files when using `--keep-search-results`. |
| `--fasta_url` | As for Foldseek: adds the SCOP-labelled copy `analyze_label/<stem>_sgpval.tsv`. |

**By default, only `<stem>_sgpval.tsv` is kept.**

Add `--keep-search-results` before or after `search` to retain the original hits at
`<output>` and shuffled hits at `reseek_output_<signature>/shuf_result.tsv` for
inspection or reuse. For example, append the flag to the Reseek command above.

The output `<stem>_sgpval.tsv` holds `aq query target evalue pvalue sgpval`, and the SG
p-value is computed from the AQ score. Reseek reshuffles the query against every target,
using a random seed per thread, so its decoys **cannot be seeded**. Repeated runs give
slightly different SG p-values.

## Data

The paper's data are on [Zenodo](https://doi.org/10.5281/zenodo.23872787):
There is one `data_` archive (experiment inputs) and one `results_` archive (processed
results) per experiment. Results include:
- query identifiers and reference labels;
- background scores from the randomized (decoy) searches;
- search results with alignment scores, native E-values and SG p-values.
